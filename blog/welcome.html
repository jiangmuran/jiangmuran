写在这里

关于为什么开这块自留地，以及它会长成什么样。

杂记元

起点

这块小地方，是给那些够长写不进朋友圈、够私发不进 Twitter、够杂塞不进项目 README 的东西准备的。

可能是一次踩坑的复盘，一段读完一本书的散记，一个突然冒出来需要写下来才能想清楚的念头。

风格

不堆 SEO 关键词、不每篇都配封面图、不写"今天我学到了 5 件事"。

就是写。

像把书房里的便签从抽屉里翻出来，整理一下，让它能被搜索到、能被分享、能在五年后我自己回来找的时候还认得出来。

这块博客的几条约束

约束 原因
一篇一个主题 不写综述帖
中英不混排 单篇内部统一
代码块要能 copy 不为装饰
不写鸡汤 也不写凡尔赛

关于代码

如果文章里贴代码，会是这种风格：

// 一个简单的 TypeScript 例子
function welcome(name: string): string {
  return `Hello, ${name}. 欢迎来到这里。`;
}

const greeting = welcome("Reader");
console.log(greeting);

或者：

def fibonacci(n: int) -> list[int]:
    """前 n 个斐波那契数"""
    seq = [0, 1]
    while len(seq) < n:
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

这块博客能写点什么

后来我把写作系统扩了扩,现在除了普通 Markdown,还能写"会动"的东西:

新增能力
