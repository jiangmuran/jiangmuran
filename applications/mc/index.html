JMR Minecraft online

这是一个本地化的 1.8.8 WebMC 启动主页，提供 WASM 高性能版 与 JS 高兼容版。 如果你用的是较新桌面浏览器，优先选择 WASM；如果设备较旧或兼容性有问题，再切换到 JS。 首次打开需下载大约 20M 数据；若为移动端设备，还会额外加载移动端触控系统。

推荐 性能优先

更高帧率、更低卡顿，适合桌面端 Chrome / Edge 新版本浏览器。

启动 1.8.8 JS

兼容优先 低门槛

运行速度相对慢，但对设备和浏览器要求更低，适合“先能跑起来”。

立即启动 JS 版本

版本说明

  • 两个版本均基于同一代 1.8.8 客户端思路，但运行时实现不同（WASM 与 JS）。
  • 若你遇到黑屏、卡住、崩溃，建议先尝试刷新并切换另一个版本。
  • 本地存档与设置保存在浏览器本地存储中，清理浏览器数据会导致丢失。

注意事项

  • 两个玩家如果要联机，需要连接到同一中继服务器，并输入邀请码加入同一个游戏。

功能支持

  • 支持光影效果（浏览器与设备性能允许时）。
  • 支持放大类 Mod 功能体验。
  • 支持联机、多人服务器连接与游玩。
  • 支持屏幕录制相关功能。
  • 支持自定义皮肤等常用扩展能力。
